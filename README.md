# AZIX Restaurant Website

A responsive restaurant website created using HTML and CSS.

## About the Project

AZIX Restaurant is a practice web development project featuring a restaurant homepage, food menu, and contact information.

## Technologies Used

- HTML5
- CSS3

## Features

- Navigation menu
- Home, Menu, About and Contact sections
- Food cards with images
- CSS Grid layout
- Hover effects and animations
- Responsive design for mobile devices
